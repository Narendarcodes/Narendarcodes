## Developer Profile

I build practical software around AI agents, backend automation, learning tools, and productivity systems. Most of my work sits at the point where a model needs to call real tools: APIs, databases, queues, browser extensions, calendars, and user-facing workflows.

My current public focus is simple: ship useful projects, document them cleanly, remove unsafe defaults, and make each repo easier for another developer to run.

```yaml
handle: Narendarcodes
focus:
  - agentic AI workflows
  - backend APIs and automation
  - browser productivity tooling
  - student learning systems
  - practical ML integrations
working_style:
  - build the system first
  - make setup reproducible
  - keep secrets out of source
  - write READMEs that explain the real state of the project
```
